# Frontend

Static web application served by `nginx` under `/app/`.

Responsibilities:
- sign in and register users against the auth service
- restore sessions through refresh cookie
- create, list and delete user-owned short URLs
- expose the public short links generated by the shortener service

Runtime model:
- `frontend` serves HTML/CSS/JS
- `frontend` proxies `/auth/*` to `services/auth`
- `frontend` proxies `/api/*` and `/{shortID}` to `services/shortener`

Open the UI at:

```bash
http://localhost:3000/app/
```
