# Shortener Service

URL shortener backend service.

Run from the repository root:

```bash
go run ./services/shortener/cmd/shortener
```

Run tests from the repository root:

```bash
go test ./services/shortener/...
```

Optional PostgreSQL configuration:

- `DATABASE_DSN`
- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`
- `DB_SSL_MODE`
